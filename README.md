# CHARVIS v2.0

Asistente de Inteligencia Artificial profesional con interfaz inspirada en ChatGPT/Claude.

## Características
- 🎤 **Voz y Audio**: Transcripción con Whisper y síntesis con ElevenLabs.
- ⌨️ **Chat de Texto**: Interfaz fluida y moderna.
- 📎 **Archivos**: Análisis de documentos y código adjunto.
- 🎨 **Diseño Premium**: Estética limpia y profesional.

## Instalación
1. `npm install`
2. Configurar `.env` con tu `GROQ_API_KEY`.
3. `npm run dev`

## Deploy
Para despliegue real con soporte de WebSocket, se recomienda **Railway.app** o **Render.com**.
